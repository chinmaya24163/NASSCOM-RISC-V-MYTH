# 0-RV_D1SK1_L1_Introduction

## Overview

This lecture introduces the NASSCOM RISC-V based MYTH (Microprocessor for You in Thirty Hours) program conducted by VSD (VLSI System Design).

The session gives a high-level overview of:
- the course structure
- RISC-V fundamentals
- the hardware-software relationship
- the learning roadmap for the workshop

---

## Objectives of the Program

The workshop aims to teach:

- Fundamentals of RISC-V ISA
- GNU compiler toolchain usage
- ABI and verification flow
- Digital logic using TL-Verilog
- Basic and pipelined RISC-V CPU microarchitecture
- Hands-on implementation using Makerchip

---

## Key Topics Covered

### 1. Introduction to RISC-V
- Open-source Instruction Set Architecture (ISA)
- Modular and extensible architecture
- Widely used in academia and industry

### 2. From Software to Hardware
Understanding how:
- C programs are compiled
- assembly instructions are generated
- instructions execute on hardware

### 3. Course Structure
The workshop is divided into:
- Day 1 → RISC-V ISA and toolchain
- Day 2 → ABI and verification flow
- Day 3 → Digital logic and TL-Verilog
- Day 4 → Basic CPU microarchitecture
- Day 5 → Pipelined RISC-V CPU

---

## Tools Used

- GNU Compiler Toolchain
- Spike Simulator
- TL-Verilog
- Makerchip IDE
- Icarus Verilog

---

## Learning Outcome

By the end of the workshop, the learner will:
- understand RISC-V fundamentals
- work with assembly and compiler flows
- build logic in TL-Verilog
- understand CPU datapaths and pipelining
- implement a simple pipelined RISC-V CPU
